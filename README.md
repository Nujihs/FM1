# PIXEL FM · 像素电台

一个复古像素风格的多源音乐播放器。

## 功能特点

- **音乐库**：支持 QQ 音乐、网易云音乐、本地音频文件
- **AI 副驾**：接入 DeepSeek/OpenAI 兼容 API，智能聊天与歌曲推荐
- **心情点歌**：选择心情 + 查看天气，AI 为你推荐 5 首歌曲
- **实时天气**：自动获取当前位置或手动设置城市的天气
- **个性化设置**：
  - 9 种壁纸（Unsplash + 生成式像素场景）
  - 面板透明度调节
  - 6 种主题颜色
- **键盘快捷键**：空格（播放/暂停）、左右方向键（上一首/下一首）

## 使用方法

直接在浏览器中打开 `index.html` 即可运行。

### 配置 AI

1. 点击右上角 `⚙ SETTINGS`
2. 在 AI 设置中填入 Endpoint、Model、API Key
3. 推荐使用 DeepSeek（费用低、效果好）

### 添加音乐

- **本地文件**：切换到「本地文件」标签，上传 mp3/flac/m4a/wav 音频
- **免费歌曲**：点击「🎵 免费歌曲」按钮添加 12 首免版权音乐
- **QQ/网易云**：添加歌曲格式为「歌名 — 歌手」，点击可在对应平台播放

## 技术栈

- 纯原生 HTML/CSS/JavaScript（单文件）
- Web Audio API
- LocalStorage 持久化配置
- Open-Meteo 免费天气 API
